# license-plate-recognition# License Plate Recognition

This is a deep learning project for detecting and recognizing license plates from images using PyTorch.

## Description
The project focuses on building a model that can detect license plates and recognize the characters from images. It is part of an ongoing course project.

## What I did
- Built and tested neural network models using PyTorch
- Experimented with different parameters such as learning rate and number of layers
- Worked on improving model performance and accuracy
